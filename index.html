Night Light for COSMIC

A COSMIC panel applet that toggles a warmer, lower-blue screen tint with one click. This is its signed apt repository for Debian, Ubuntu and Pop!_OS (amd64); COSMIC panel is required.

GitHub repository and documentation · Download the public signing key (key.gpg)

Install with apt

Add the signed repository once; updates then arrive with your normal system updates. First download the key to a temporary file and check its fingerprint before you trust it:

key=$(mktemp)
curl -fsSL https://deepthinker2001.github.io/cosmic-ext-nightlight/key.gpg -o "$key"
gpg --show-keys --with-fingerprint "$key"

The fingerprint printed must be exactly:

0472 CEF0 1CE0 E79E C118  662D 34A0 6EB9 79E5 8584

If it differs, run rm "$key" and stop. If it matches, trust the key and add the repository (in the same terminal, so $key is still set):

sudo gpg --dearmor -o /usr/share/keyrings/cosmic-ext-nightlight.gpg "$key"
rm "$key"
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/cosmic-ext-nightlight.gpg] https://deepthinker2001.github.io/cosmic-ext-nightlight stable main" \
  | sudo tee /etc/apt/sources.list.d/cosmic-ext-nightlight.list
sudo apt update
sudo apt install cosmic-ext-nightlight

Then follow the instructions to add it to the panel.
